# 华策资治通鉴 · 三人物四相十六型推演

| 维度      | 孙膑        | 庞涓             | 白起        |

| 骨       | 修（清瘦）     | 敦偏修（方重收窄）      | 敦（横阔）     |
| 皮       | 淡（内收）     | 淡偏浓            | 极淡        |

**同质化风险**：三人同落洞察者象限（淡×锐），拉开差异的关键在皮相浓度和面部细节——孙膑靠疤痕和清瘦制造"残缺感"，庞涓靠偏文气的山羊胡和内沉眼神制造"阴鸷感"，白起靠缝眼和完全松弛的面部肌肉制造"无情绪压迫感"。

## 二、孙膑

### 小传内核

寡言深沉、心思缜密、志在大道。受刑后"冷峻清醒"、隐忍决绝。表面残烛，内里深渊。"不动如山，动则雷霆。"

### 四相编码：修·淡·聚·锐 = 洞察者（修系）

- **骨·修**：身形清瘦、眉骨高耸眼窝深陷，面部纵向延伸，视觉重心高
- **皮·淡**：目光极静，布衣素袍，五官不张扬，长时间凝视才有压迫力
- **形·聚**：心思缜密、洞察全局——眉骨高+眼窝深=面中密度高
- **神·锐**："静到使人不敢与之久对"——皮薄骨显、冷峻线条、硬触感

### AI出图参数

**基础骨相**

- 脸型：窄长偏瘦削，颧骨不外扩但可见，下颌线清晰收敛
- 眉骨：高耸（骨相结构，非化妆阴影），眼窝自然深陷

**五官参数**

- 眼：细长型，眼睑略沉，瞳孔位置偏上（制造"俯视"感），眼神极静
- 眉：清秀眉形，不浓密，与清瘦骨相协调
- 鼻：直挺偏窄，与窄脸协调
- 唇：薄唇，自然色，无表情时微抿

**肤色与质感**

- 肤色：偏黄暗（非健康光泽感），有经历感
- 皮肤质感：薄、骨感明显，不饱满

**面部细节（核心辨识符号）**

- 黥痕：面部刺字疤痕——孙膑的核心视觉标记，不可省略
- 位置：面部侧面或颧骨区域，历史记载刺字于面

**须发**

- 整体偏稀疏、早白，不是浓密大胡子
- 须发状态随年龄变化（见版本差异）

### 版本差异


| 参数   | 版本A（初仕魏国·30岁） | 版本B（齐国军师·50岁马陵前后） |
| ---- | ------------- | ----------------- |
| 整体气质 | 清秀年轻，尚存一丝温度   | 骨相更硬、面更瘦、压迫感拉满    |
| 黥痕   | 无（受刑前）        | 明显可见              |
| 须发   | 黑色或微白，较少      | 花白、稀疏             |
| 眼神   | 沉静中有温度        | 纯粹冷峻、无温度          |
| 肤色   | 偏白但非红润        | 偏黄暗、经历感加重         |
| 体态   | 可直立           | 坐于辎车/木轮（受刑后）      |

## 三、庞涓

### 小传内核

锋芒毕露但被嫉妒与不安撕扯的困兽。AI分析方向："阴鸷但克制——不是莽将的外露感，是收着的、往里沉的那种压迫感。"身体骨架高大魁梧，但头面部收窄有棱——形成"身压你、脸冷沉"的矛盾压迫。

### 四相编码：敦偏修·淡偏浓·聚·锐 = 洞察者（敦系·修边界）

- **骨·敦偏修**：整体方重（肩宽背厚），但"长方脸偏窄，颧骨不高，下颌收窄但有棱"——敦相为主，接近敦修边界态
- **皮·淡偏浓**：单眼皮/内双眼睑沉（淡），但浓眉、武将威慑感（浓），居中偏淡
- **形·聚**：眉头平直下压、眼神冷静向下压——面中紧收、精神集中的压抑态
- **神·锐**：阴鸷克制，皮薄骨显、不圆润，收着往里沉的硬触感

### 与白起的差异锚点

同为敦系洞察者，但：

- 庞涓的"聚"是**有情绪的聚**——嫉妒、不安、心魔，面部有微弱紧张
- 白起的"聚"是**无情绪的聚**——完全松弛的冷酷，毫无内耗
- 庞涓的"锐"是**向内的锐**——困兽的阴鸷
- 白起的"锐"是**向外的锐**——刀锋的冷硬

### AI出图参数

**基础骨相**

- 脸型：长方偏窄，颧骨不高，下颌收窄但有棱角（不是宽大方脸）
- 额骨：适中
- 整体骨架：高大魁梧、肩背宽阔（身体走敦、脸走敦修边界）

**五官参数**

- 眉：平直略下压，眉头自然不蹙（不是一字眉也不是怒眉）
- 眼：单眼皮或内双，眼睑略沉，眼神向下压但是冷静的（不是愤怒的）
- 鼻：山根高挺，直
- 下颌：收窄但有棱

**肤色与质感**

- "略有岁月感但不粗粝"——养尊处优的武将，不是底层兵卒
- 不画粗糙毛孔和深皱纹

**须发（核心辨识符号）**

- 山羊胡：稀疏细长——偏清瘦文气，这是他和传统猛将造型的核心区分
- 下颌：少量短须
- 整体胡须偏清瘦，不是浓密的大胡子
- 鬓角：隐约可见白发
- 发髻：整齐但略显随意

### 版本差异


| 参数   | 版本A（初仕魏国·30岁）    | 版本B（马陵之战·55岁）            |
| ---- | ---------------- | ------------------------ |
| 整体气质 | 锋芒外露、锐气毕露但已带阴鸷底色 | 骄矜难制、威严中有疲态与执念           |
| 肤色   | 赤铜色偏亮            | 赤铜色加深、岁月感加重              |
| 须发   | 黑色为主、鬓角无白发       | 鬓角白发明显、山羊胡更长             |
| 眼神   | 锐利但尚有向上看的野心      | 向下压的阴鸷加重、疲态显现            |
| 面部肌肉 | 微有紧张（控制中的野心）     | 更松弛但不是白起那种松弛——是"被撕扯后的麻木" |

## 四、白起

### 小传内核

冷峻自律、狠辣决绝、一身傲骨。不是不知杀降之罪，临死说"我固当死"——清醒到极致的残酷。"忠于塑造他、成就他，也最终毁灭他的秦国。"他是战国最可怕的将军，也是秦国统一道路上最锋利的刀。

### 四相编码：敦·极淡·聚·锐 = 洞察者（敦系）

- **骨·敦**：方脸型、高大威严、下颌方重——横向支撑强、低重心
- **皮·极淡**："双眼如缝"——五官量感极小，淡到极限，但"缝里透出来的光"制造极端压迫
- **形·聚**：冷峻自律——面中紧收、精神高度集中的绝对态
- **神·锐**：皮薄骨显、线条硬朗、所有折角清晰——完全无亲近感的硬触感

### 核心视觉逻辑

白起的可怕不在"做"表情，在于他不"做"表情。他的面部应该像一面钝器——没有多余的情绪波动，所有表情都被压平。这种"无表情的压迫感"是他和庞涓的根本差异。

### AI出图参数

**基础骨相**

- 脸型：方脸，宽下颌，颧骨可见但不夸张，整体横阔
- 骨骼：粗大扎实，所有线条硬朗直线
- 下颌：折角清晰、方正

**五官参数**

- 眼（核心特征）：极窄——"如缝"，单眼皮，上眼睑下垂但瞳孔完全可见，眼神不怒自威。不画睁大的眼睛、不画怒目
- 眉：浓密、平直，不弯曲，不蹙眉
- 鼻：直挺，鼻梁硬朗
- 唇：薄、紧抿、无表情

**肤色与质感**

- 饱经风霜：比庞涓更粗粝（底层出身 vs 贵族养尊处优）
- 皮肤质感：厚实但不是饱满，岁月感重
- 不画细腻光泽感

**须发（核心辨识符号）**

- 浓密须髯：全须全髯（从年轻时蓄起），花白
- 发型：秦人典型发髻，整齐严谨
- 鬓角：浓密花白

### 版本差异


| 参数   | 版本A（伊阙成名·约35-40岁） | 版本B（长平之战·近70岁）              |
| ---- | ----------------- | --------------------------- |
| 整体气质 | 冷酷但尚有"刀新磨出"的锐利感   | 极致冷峻、已完成所有内心博弈、"老刀归鞘前的最后一挥" |
| 须发   | 黑色为主、少量花白         | 全花白、浓密                      |
| 肤色   | 风霜感中等             | 极重风霜、粗粝                     |
| 眼    | 极窄、缝状、冷光          | 同上但更深邃、仿佛无光（老将的空洞）          |
| 面部肌肉 | 完全松弛、无多余表情        | 同上但更"空"——不是疲惫是看穿一切后的虚无      |
| 体态   | 高大挺拔              | 略微佝偻（年事已高）但骨架仍大             |
